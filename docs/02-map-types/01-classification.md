# Как классифицировать карты данных

Карта может быть построена на одном из нескольких принципов:

* карты данных основанные на ответах на вопросы;
* карты данных, основанные на полномочиях и государственных системах в иерархии: ведомство -> полномочия -> ГИС -> реестры данных
* карты данных, основанные на итоговом продукте, который предполагается создавать с использованием данных
* карты данных, основанные на доступности данных. При этом карта не даёт полной картины данных, для которых также важны характеристики их интегрируемости, возможности связывать с другими источниками информации, актуальность и многие другие аспекты.

:::note[Черновик]
Глава будет переписана как единая классификация по трём осям:

- от чего строится карта: вопросы, полномочия органов власти, итоговый продукт, доступность;
- глубина: три уровня (тема → вопрос → источник) или четыре (с типовыми темами);
- форма: интеллект-карта, доска с колонками, таблица, граф.

Каждый вид из следующих глав — сочетание значений этих осей. Например, карты атласа — карты от вопросов в три уровня в форме интеллект-карты с разметкой доступности.
:::

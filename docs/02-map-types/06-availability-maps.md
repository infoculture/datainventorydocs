# Карта доступности

Карта доступности — это карта данных в виде доски с колонками (канбан): карточки систем организованы в виде списков в столбцах, каждый столбец — орган власти.

Доступность данных определяется цветовой рамкой карточки источника данных.

Используется следующая цветовая классификация:

* зелёный цвет — доступны открытые данные
* синий цвет — сведения доступны, но в неструктурированных форматах
* жёлтый цвет — сведения доступны с ограничениями или требуют авторизации
* красный цвет — система является закрытой и есть юридические ограничения
* серый цвет — не установлено: проверить не удалось

Критерии каждого цвета и чем его подтвердить — в [шкале доступности](../03-method/05-assessing-availability.md#шкала). Серый добавлен к четырём исходным цветам, чтобы непроверенный источник не окрашивался в цвет по умолчанию.

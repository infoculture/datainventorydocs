# Владельцы, системы, ресурсы, задачи

Моделирование владельцев, систем, ресурсов и задач (ВСРЗ) необходимо для визуализации необходимых и достаточных источников данных. В центр карты помещаются продукты/результаты которые предполагается создать на их основе, каждая система и информационные ресурсы в них описываются с точки зрения их использования с конечными продуктами. 

На примере ниже итоговые продукты — единый реестр объектов законотворчества и нормативных правовых актов и анализ финансово-экономических обоснований (ФЭО). Вокруг них — системы, из которых берутся данные, и ресурсы этих систем.

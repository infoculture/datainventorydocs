# Карта с предопределёнными темами

Карта с предопределёнными темами — это четырёхуровневый вариант [карты от вопросов](./02-question-maps.md): между темой и вопросами находятся предопределённые темы — группы вопросов, повторяющиеся от отрасли к отрасли.

Предопределённые темы:

* Статистика — различные статистические показатели
* Организации — сведения о юридических лицах
* Финансы — сведения о финансах организаций, бюджетах, контрактах и так далее
* Люди — сведения о физических лицах
* Ресурсы — сведения об иных информационных ресурсах и объектах.

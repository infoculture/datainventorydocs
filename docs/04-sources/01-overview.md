# Источники данных о данных

Здесь собран перечень ресурсов используемый для поиска информационных систем, ресурсов и баз данных необходимых для построения карт данных. Все они помогают собрать общую картину источников данных.

| Наименование | Описание | Ссылка |
| :--- | :--- | :--- |
| Открытые данные на сайте ФГИС Координация информатизации | Общедоступные сведения о информационных системах публикуемые на сайте ФГИС КИ | [https://portal.eskigov.ru/opendata](https://portal.eskigov.ru/opendata) |
| Реестр ФГИС (до 2013 года) | Реестр переданный Минкомсвязи из Роскомнадзора с расширенным описанием паспортов систем | [https://portal.eskigov.ru/fgis](https://portal.eskigov.ru/fgis) |
| Реестр государственных контрактов | В части контрактов заключённых на создание или сопровождение ИТ систем | [https://spending.gov.ru/goscontracts/](https://spending.gov.ru/goscontracts/) |
| Реестр государственных субсидий | В части госзаданий на создание государственных информационных систем | [https://spending.gov.ru/subsidies/](https://spending.gov.ru/subsidies/) |
| Официальные сайты органов власти | В разделах: Планы информатизации, "Государственные информационные системы" и "Государственные информационные ресурсы" | [http://government.ru/ministries/](http://government.ru/ministries/) |
| База законодательства РФ | В части законов, постановлений, указов и приказов о создании информационных систем | [https://pravo.gov.ru](https://pravo.gov.ru) |
| Реестр государственных доменных имён | В части общедоступных интерфейсов информационных систем и ресурсов | [https://github.com/infoculture/govdomains/](https://github.com/infoculture/govdomains/) |
| Частные системы | Частные информационные системы и реестры относящиеся к теме | Поиск в сети интернет |

# Как читать атлас

В атласе — четыре отраслевые карты данных, составленные в 2018–2019 годах: государственные финансы, нефть и газ, здравоохранение, образование. Все они построены [от вопросов](../02-map-types/02-question-maps.md): на каждый вопрос дан список источников, и у каждого источника отмечено, доступны ли в нём сведения. Карты хранятся как данные, таблицы на страницах атласа строятся из них. Доступность — по легенде 2018–2019 годов и с тех пор заново не проверялась.

## Легенда

На картах для печати доступность отмечена ромбами трёх цветов. В таблицах атласа те же цвета показаны кружками.

| Отметка | Легенда исходной карты | Что это значит по [шкале доступности](../03-method/05-assessing-availability.md#шкала) |
|---------|------------------------|-----------------------------------------------------|
| <span className="avail avail--available">●</span> | Данные доступны | открытые данные или неструктурированные сведения — карты 2018–2019 годов эти статусы не различали |
| <span className="avail avail--restricted">●</span> | Данные доступны с ограничениями | с ограничениями: регистрация, плата, договор |
| <span className="avail avail--unavailable">●</span> | Данные не доступны | закрыто — или нет внешнего доступа, а основание не установлено |
| <span className="avail avail--unknown">○</span> | — | доступность не указана: пары нет на карте для печати |

На интеллект-картах источники подчёркнуты цветными линиями. Красные и жёлтые линии в основном совпадают с ромбами карт для печати, но легенды у интеллект-карт нет, а доступные источники подчёркнуты по-разному: на карте здравоохранения — бирюзовым, тёмно-зелёным и синим. Поэтому доступность в атласе взята с карт для печати, где легенда есть.

Чтобы перевести карту на пятиуровневую шкалу, каждую пару нужно проверить заново по [порядку проверки](../03-method/05-assessing-availability.md#порядок-проверки). Это задача следующей версии атласа.

## Как устроена страница карты

Все страницы атласа устроены одинаково:

1. **Паспорт** — тема, вид карты, дата проверки, число вопросов и источников, откуда сведения, автор, лицензия, ссылка на данные.
2. **Вопросы и источники** — главная таблица карты.
3. **Источники карты** — каждый источник один раз, с владельцем и номерами вопросов, на которые он отвечает.
4. **Визуализации** — интеллект-карта и карта для печати.
5. **Файлы для скачивания** — картинка, PDF, таблица CSV и файл данных YAML.
6. **Что изменилось** — история карты и решения, принятые при её переносе в данные.

Как устроен файл данных, рассказано в главе [«Карта как данные»](../05-tools/03-maps-as-data.md).

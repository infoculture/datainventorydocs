# Чек-листы

Чек-листы собраны из глав о методе. Каждый пункт ведёт к главе, где он объяснён.

## Перед началом

- [ ] Известно, кто заказчик карты и для какой задачи она нужна ([«Зачем нужны карты данных»](../01-basics/02-why-and-for-whom.md)).
- [ ] Выбран вид карты ([«Как выбрать вид карты»](../02-map-types/07-choosing.md)).
- [ ] У темы записаны границы: территория, уровень власти, кто кроме государства ([«Выбор темы и подбор вопросов»](../03-method/02-topic-and-questions.md#тема)).
- [ ] Список вопросов согласован с заказчиком до поиска источников ([«Как проверить список вопросов»](../03-method/02-topic-and-questions.md#как-проверить-список-вопросов)).
- [ ] Заведена рабочая таблица ([шаблоны](./03-templates.md#рабочая-таблица)).

## Перед публикацией

- [ ] У каждого вопроса есть хотя бы один источник или пометка «источник не найден».
- [ ] Каждый источник отвечает хотя бы на один вопрос.
- [ ] У каждого источника есть владелец.
- [ ] У каждого статуса доступности есть основание и дата проверки.
- [ ] Нет одного источника под разными именами.
- [ ] Источники описаны с одинаковой подробностью, группы помечены.
- [ ] Ссылки открываются; российские государственные сайты проверены из российской сети.
- [ ] Карту посмотрел эксперт отрасли.
- [ ] Есть паспорт: тема, вид, дата, автор, лицензия, откуда сведения.
- [ ] Опубликована таблица или данные, а не только картинка.

Подробнее — в главе [«Проверка и публикация»](../03-method/06-review-and-publish.md).

## При обновлении

- [ ] Проверены все адреса: какие исчезли, какие переехали ([«Обновление карты»](../03-method/07-maintenance.md#что-устаревает-первым)).
- [ ] Сверены владельцы с актуальным перечнем органов власти.
- [ ] Проверен статус нормативных актов, на которые опираются источники.
- [ ] Перепроверены статусы доступности по [порядку проверки](../03-method/05-assessing-availability.md#порядок-проверки).
- [ ] Исчезнувшие источники не удалены, а помечены; где возможно, добавлена ссылка на веб-архив ([«Унаследованные и закрытые системы»](../04-sources/10-legacy-systems.md#как-отметить-на-карте)).
- [ ] Записан список изменений и новая дата.

## Перед ссылкой на нормативный акт

- [ ] Акт действует — нет отметки «утратил силу».
- [ ] Взята последняя редакция, она указана в ссылке.
- [ ] Нет принятых, но не вступивших в силу изменений.
- [ ] Записана дата проверки.

Подробнее — в главе [«Нормативные акты и полномочия»](../04-sources/05-legal-acts.md#как-проверить-редакцию).

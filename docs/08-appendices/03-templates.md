## Рабочая таблица

Три листа из главы [«Доски и таблицы»](../05-tools/02-boards-and-tables.md#рабочая-таблица). Файлы в кодировке UTF-8, разделитель — запятая.

- [sources.csv](pathname:///templates/sources.csv) — источники: `id`, `name`, `type`, `owner`, `legal_basis`, `level`, `url`, `aliases`, `known_from`;
- [questions.csv](pathname:///templates/questions.csv) — вопросы: `n`, `text`, `theme`;
- [links.csv](pathname:///templates/links.csv) — связи «вопрос — источник»: `question_n`, `source_id`, `status`, `status_basis`, `checked`.

Значения `status` — по [шкале доступности](../03-method/05-assessing-availability.md#шкала): `open` (открытые данные), `unstructured` (неструктурированные сведения), `restricted` (с ограничениями), `closed` (закрыто), `unknown` (не установлено).

## Файл карты

Заготовка в формате атласа этой книги: [map.yaml](pathname:///templates/map.yaml). Схема полей — [`data/README.md`](https://github.com/infoculture/datainventorydocs/blob/master/data/README.md), разбор — в главе [«Карта как данные»](../05-tools/03-maps-as-data.md).

```yaml
id: my-topic
title: Моя тема
kind: [questions, availability]
checked: 2026-10
author: Имя Фамилия
questions:
  - n: 1
    text: Где найти …?
    sources:
      - {source: some-source-id, availability: available}
```

Атлас пока хранит доступность по легенде карт 2018–2019 годов (`available`, `restricted`, `unavailable`). Для новой карты лучше сразу записывать статус по пятиуровневой шкале, как в `links.csv`.

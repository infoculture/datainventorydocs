# Введение

**Карты данных** — это одна из форм представления источников данных, связанных с конкретной темой или территорией. Карта отвечает на вопрос: "Где найти данные?" ответами на который являются адреса и описания информационных систем, их владельцев и описания качества и структуры хранимых данных.

Работа по картированию данных имеет много зависимостей от предметной области и целей для достижения  которых она создаётся. 

Это [руководство](guide.md) посвящено созданию карт данных привязанных к данным создаваемых или регулируемых государством и данных связанных с задачами по построению продуктов основанных на данных.

В разделе [Карты данных](datamaps/) приведены примеры уже созданых тематических карт данных, а также доступны основные [источники данных](sources.md) используемые для сбора информации для каждой карты данных.
